# calibration/ — test fixtures disguised as compositions

Gradient documents (§8): pages that sweep exactly one parameter in one
direction, so the census can be checked against material whose truth is
known by construction. The discipline: census the left third vs the
right third — the vectors MUST differ in the swept parameter, and only
meaningfully in it. If a code change moves the density number on a
density gradient, fine, argue about it in the diff. If it moves the
symmetry number, something's leaking between measurements.

Current fixtures:

- `density-sweep-lr.txt` — ink thins left→right. Generated by the same
  arithmetic formula as `densityGradientLR()` in
  `packages/core/test/census.test.ts` (no RNG — fixtures don't need
  dice, they need to be boringly knowable). The automated test lives
  there; this file is the human-eyeballable copy.

Wanted, eventually: grain sweep (T→B), run-length sweep, symmetry sweep,
a stack-depth gradient (plain→zalgo). Per the spec: hang them in the
commons later — they're compositions too.
