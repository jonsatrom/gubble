# captures/ — the session record, kept local

Screen recordings, GIFs, and screenshots documenting the instrument as it
grows — the studio's field notes. Named `YYYY-MM-DD-what-it-shows.ext` so
future archaeology is possible without opening anything.

Contents are **gitignored** (this README is the only file that travels):
these are working captures for conversations and documentation, not
release assets. If one ever earns a place in the public repo — a README
hero, a release note — it gets deliberately promoted out of here, not
accidentally committed from here.

First entry, for the record: `2026-07-15-m2-first-sound.gif` — the M2
instrument's first recorded performance. Three corners loaded, puck
drifting, phase at 0.7, and the discovery that PHASE's stable cells read
as smudges on glass — the observation that ratified "strata" into the
vocabulary (§1, §19).
